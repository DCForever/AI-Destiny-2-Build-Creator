How finish works

  1. Armor · Weapons · Mods must each reach complete fill (owned or wish) for finish status.
  2. Equip-ready requires every combat slot to be an owned instance pin — wishes do not equip.
  3. Apply and Copy DIM JSON share the same gate: equip-ready finish only.
  4. Soft guidance (stat target sliders, super coverage) is confirm-only — never blocks save or equip.
  5. Optional exotic / super pins inform identity chips; they do not replace loadout slots.
