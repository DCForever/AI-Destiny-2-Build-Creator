1. System identity

Vex Network Interface is a production design system for dense, high-signal network / ops / construct product UI. Atmosphere is void + cyan-neon energy. Chrome is angular and modular. Layout uses space and gradient dissolves—not outlined card cages. Motion is mechanical and intermittent.

2. Voice & vocabulary

Tone: Cold digital logic made visible. Short technical labels. Geometric certainty. Zero organic warmth. Operational, not marketing.

Adjectives: modular, emissive, precise, weightless, mechanical, high-contrast, computational.

Prefer: network, node, module, signal, link, sync, stream, grid, void, wireframe, transmit, calibrate, status, channel, config, engage.

Avoid: warm/friendly, delightful, cozy, organic, soft rounded comfort, synergy, seamless journey, empower.

3.3 Glow, gradient, environment

  • --glow-pulse — peak live-signal glow
  • --grad-signal — cyan → blue → magenta (transmission paths, sparse energy)
  • --grad-tx — packet sweep gradient for dividers/paths
  • --grad-fade / --grad-zone — soft spatial zoning (primary arrangement tools)
  • --grid-line — Tron perspective floor only (faint underlay when photo stage owns the grid)
  • --env-photo-opacity / --env-bloom-opacity — photographic stage + sparse blooms (Lane A)

  • Dense UI body ~12–14px; display stays technical, not marketing-hero scale.
  • Kickers/meta: mono uppercase, tight tracking.

5. Shape, space, density

  • --radius: 0 default; max 2–4px sparingly.
  • Space scale: 4 / 8 / 12 / 16 / 24 / 32 / 48.
  • Inside modules: high density (4–12 gaps, tight fields/tables).
  • Between regions: more air (16–48); separate with gap + tonal step + gradient fade.
  • Control height: 36–40px dense; touch targets ≥44px where practical.
  • Borders: optional hairline white/grey. Default panel is not a closed outline box.

6. Layout posture (v1.1)

Arrangement language (prefer in order)

  1. Whitespace / gap between sections and columns
  2. Tonal surface steps (--surface / --surface-2 / void)
  3. Gradient fades (dissolve edges into bg)
  4. Hairline white/grey dividers (lists, tables)
  5. Full outlined boxes — exception only (modal, critical alert, temporary focus cage)

Neon as complement

Use cyan/magenta for: primary CTA + focus (≤ ~2 strong hits per view region); selected nav; live pulse; sparse transmission packets that point at content.

Do not use neon for: default panel outlines; every divider; body text color; full-page gradient washes.

Environment

  • Canonical stage: image.png (wire mega-platform + horizon grid) under content with readability scrim/vignette.
  • CSS Tron ground plane is a faint underlay only when the still already carries the grid — never a flat full-viewport wallpaper tile.
  • Supporting stills: josh-markham-vex-02.jpg … 06.jpg for glow/platform falloff reference.

7. Motion

Signal-fade envelope (shared by live pulse and divider/path packets):

Phase~ShareSignal opacity
Off / rest~18%0
Fade in~10–12%0 → peak
Hold / travel~30–45%peak
Fade out~20–25%peak → 0
  • Pulse cycle ~2s linear; divider packets ~3.4–4s linear (staggered).
  • Softest keyframe must be fully extinguished — no permanent dim cyan rest state.
  • Grey structure hairline stays static; cyan is only the moving packet.
  • Enter/state transitions: linear or ease-out, 150–300ms. No bounce/spring.
  • prefers-reduced-motion: freeze pulse/packets at dim/off (~0.28), never full-intensity neon; kill continuous loops.

8. Iconography

  • Geometric line icons only — no emoji, no soft illustration.
  • Stroke 1–1.5px; angular caps; 16 / 20 / 24 boxes.
  • Default: white/grey; active: accent cyan; critical: danger.
  • Pair icon + label for density; icon-only only with aria-label (+ tooltip in kit).

10. Usage rules (acceptance)

  1. Accent cyan ≤ ~2 strong applications per view region (CTA + focus/selected).
  2. Multicolor gradient never as a full-page wash.
  3. Borders/dividers default white/grey; cyan only for active wire / live packet.
  4. Continuous network signals fully fade to near-zero each cycle.
  5. Text contrast holds without glow (dark and light).
  6. Radius default 0; never exceed 4px.
  7. Dense fields inside modules; air between regions.
  8. Motion mechanical; reduced-motion freezes signals dim, not full neon.
  9. No emoji icons; no purple SaaS wash; no warm beige canvas.
  10. Background reads as image.png atmosphere; CSS floor is underlay only.
  11. Light theme stays cool technical twin, not Material-pastel consumer.

Do

  • Zone with gap + tonal steps + fade edges
  • Grey structure first; neon as intermittent signal
  • Orbitron display / Inter body / mono metrics
  • Composite reference still under scrim for stage fidelity
  • Honor reduced-motion with frozen dim signals

Don’t

  • Default every module as a strong outlined box
  • Cyan wireframe cages on all panels
  • Permanent dim glow “always online” pulse
  • Flat orthographic grid wallpaper
  • Purple SaaS gradients, emoji icons, soft bounce motion

11. Platforms

  • Desktop web (dense) — primary kit density; hover + keyboard focus glow
  • Desktop app — same chrome; slightly tighter window affordances
  • Responsive web — redesign small breakpoints (collapsible nav, stacked zones, 44px targets); never squeeze bordered desktop cards
