# Destiny 2 Build Creator — Products

**Working copy and PRD corpus** for this product line. Domain / Area / Destiny Object notes **are the PRDs**. Review and edit **here** (ProjectTracker) or on the repo doc site (`npm run docs:dev`). Repo path `docs/products/` is a pointer only. Propose modifications as `CR-YYYYMMDD-###`.

Parent projects: [Destiny 2 Build Creator](/prd/destiny-2-build-creator/) (Flutter multiplatform) · [Destiny 2 Build Creator - NextJS](/prd/destiny-2-build-creator-nextjs/) (web legacy).

Product descriptions own **intent, framing, scope, and a scoped rule pack** (relevant `DBR-*` / `BR-*` / `DAC-*` with plain-language wording). Example pattern: [Domain Set](/prd/domain-set/) §6.

Repo `specs/` remains the full corpus for agents/gate. **Specs re-sync is deferred until product definitions are finished** (user gate). Until then, edited product notes are the intended product truth for that concept.

## How layers fit

| Layer | Where | Owns |
| --- | --- | --- |
| Whole product | Repo `PRODUCT.md` | Purpose, positioning, principles |
| **Product descriptions** | **This catalog (Obsidian)** | Reviewable intent/scope for domains + areas + Destiny objects |
| **Destiny objects** | [Destiny Objects](/prd/destiny-objects/) | What game entities *are*; how we show them (DIM); how domains use them |
| Structure | Repo `docs/product-map/` | Surfaces, flows, rule *attachments* |
| Rule wording | Repo `specs/domain-*.md`, `business-rules.md` | Enforceable `DBR`/`DAC`/`BR` text |
| Feature slices | Repo `specs/00N-*/` | Implementation scope |

**Precedence:** Domain rules win on conflict with feature BRs and with prose here. Fix the description if it drifts; do not implement against description-only fiction.

## Same-change discipline

When a product description’s meaning changes:

1. Edit the note in this vault  
2. Update repo domain markdown (`DBR`/`DAC`/`BR`) if semantics changed  
3. Update product-map `rules:` / surfaces if structure changed → `npm run product-map:sync`  
4. Update repo `PRODUCT.md` if whole-product framing shifts
