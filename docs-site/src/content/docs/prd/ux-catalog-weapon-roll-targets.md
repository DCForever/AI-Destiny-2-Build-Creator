# UX — Catalog Weapon Roll Targets

> [!abstract] One-liner
> Named preferred + avoid perk targets per weapon; rank owned copies by how close to ideal and how many avoid hits.

**Delivery:** [FEAT-20260807-001 Catalog weapon roll targets](/prd/feat-20260807-001-catalog-weapon-roll-targets/)

> [!warning] Not equip-ready wishlist
> **Wishlist** in domain (DBR-ROLL-*) means desired roll on a Set/Variant slot without an instance pin.  
> This feature is **Catalog roll targets** (ideal + anti-ideal). Do not overload the word “wishlist” in product copy.

## Job

- **For:** Define what I want and what I refuse on a weapon; see if owned copies are close and/or trash.  
- **Not:** Auto-dismantle, Build/Set equip push (phase 2), DIM import (optional later).

## Locked product decisions

| Topic | Choice |
| --- | --- |
| Surface | Catalog-first |
| Preferred | Multi-pick per column |
| Avoid | Multi-pick per column (anti-ideal) |
| Profiles | Named multi (PvE / PvP / …) |
| Score N/M | **Roll quality** on scored sockets: N = ideal plugs on this copy, M = all plugs on preferred/avoid sockets (equipped + reusables). Example: 3 ideals among 6 trait plugs → `3/6` (DBR-IDL-005) |
| Perfect / green tint | Every preferred **column** has a multi-accept hit — **not** N==M |
| Rank | Preferred ratio desc, then avoid hits asc, then power |
| **Exotics** | **No roll targets** (DBR-IDL-009) — exotic perks are fixed |

## Acceptance (MVP)

1. Two named targets with preferred + avoid multi-picks.  
2. Same perk cannot be Want and Avoid in one column.  
3. Owned show `N/M` roll quality + `Av k`; green when all preferred columns hit; sort high-ratio then low-avoid.  
4. Soft display only; soft never auto-applies.
