> [!abstract] One-liner
> Socket plug on a weapon: legendary column traits and exotic weapon trait/intrinsic plugs.

Hub: [Destiny Objects](/prd/destiny-objects/) · Host: [Destiny Weapon](/prd/destiny-weapon/) · Related: [Destiny Origin Trait](/prd/destiny-origin-trait/)

## 1. Definition (Destiny / DIM)

A **weapon perk** is a plug in a weapon socket that defines part of the roll or exotic identity.

| Include | Examples |
| --- | --- |
| **Legendary column traits** | Third/fourth column perks (and similar trait columns) |
| **Barrel / magazine / bowstring / etc.** | Non-trait columns that still define the roll |
| **Exotic intrinsic / trait** | Fixed exotic plugs — still **weapon_perk** for Synergy evidence (DBR-SYN-014) |
| **Enhanced / crafted trait variants** | Enhanced versions of the same family when game distinguishes them |

| Exclude (related but other objects / fields) | Why |
| --- | --- |
| [Destiny Origin Trait](/prd/destiny-origin-trait/) | Separate origin column; separate Synergy kind `origin_trait` |
| Weapon **combat mod** (e.g. Boss Spec) | Optional weapon mod socket — host [Destiny Weapon](/prd/destiny-weapon/) field / extras, not this object’s Synergy kind |
| Masterwork / shader / tracker | Cosmetics or MW state on weapon — not trait evidence |
| [Destiny Armor Mod](/prd/destiny-armor-mod/) | Armor energy plugs |

DIM shows perks in a multi-column grid with a hotspot popup for description.

### Three contexts

| Context | Meaning |
| --- | --- |
| **Selected** | Plugs on this instance or desired roll |
| **Can roll** | Manifest pool options per column for the weapon identity |
| **Craft options** | Possible crafted/enhanced choices when the weapon is craftable |

Detail must support all three when data exists ([Destiny Weapon](/prd/destiny-weapon/) detail stack).

## 2. Presentation (DIM North Star)

### Always

| Show | How |
| --- | --- |
| Perk | Icon |
| Name | Tooltip / detail primary; **never** bare plug hash |
| Enhanced | Badge when enhanced/crafted variant |

### Detail (Catalog weapon detail, Set item detail, perk hotspot)

| Block | Content |
| --- | --- |
| Selected grid | Icons for all roll-relevant columns (barrel/mag/traits/…) when product shows full roll |
| Can-roll | For each column, **all valid pool options** — not only selected |
| Craft | Possible crafted/enhanced options when craftable |
| Hotspot | DIM-like perk info popup for selected **and** pool options |
| Exotic | Label **exotic intrinsic/trait** vs legendary when known (BR-SYN-012) |
| Origin | Shown in layout but product object is [Destiny Origin Trait](/prd/destiny-origin-trait/) |

### List / row density

| Surface | Show on row | Detail only |
| --- | --- | --- |
| **Weapon Set slot row** | **No** perk icons/text (weapon icon + exotic badge only) | Full selected + can-roll + craft |
| **Catalog list row** | No full perk grid | Full perk UI |
| **Synergy link picker** | Icon + name; exotic vs legendary label when known | Description |
| **Masterwork / weapon combat mod** | Small glyph on weapon rows when known | Full treatment on weapon detail |

**Barrel / mag / non-trait columns:** same density as traits on **detail**; **not** on Set slot rows or dense Catalog list rows.

**Hashes:** never primary UI; footer addendum only (DO-WPN-010–013).

| Soft guidance | Similar-perk alternatives after remove (BR-ROLL-003 polish) |

### Validity (hard)

Selected plugs must be **valid for the item** in the manifest (including enhanced variants when claimed).  
Invalid plug on save → reject.

### Exotic traits

| Rule | Meaning |
| --- | --- |
| Fixed | Not user-rolled; still shown clearly on detail |
| Synergy | Counts as `weapon_perk` evidence |
| UI | Label exotic trait vs legendary when known |

## 5. Hard vs soft

### Hard

| Rule | Where |
| --- | --- |
| Invalid perk for weapon identity → cannot save | Weapon Set / roll validation |
| Exotic ≤1 weapon on set/loadout | Set / Variant (host weapon rule) |

### Soft

| Topic | Rule |
| --- | --- |
| Catalyst complete | Soft only on host [Destiny Weapon](/prd/destiny-weapon/) (DO-WPN-040–051); catalyst-granted trait plugs may still be `weapon_perk` evidence |
| Similar-perk suggestions | Polish after remove |
| Synergy coverage | Soft except required-link pins on default |

### Object rules

| ID | Rule |
| --- | --- |
| DO-WPK-001 | Weapon perk covers **roll plugs and exotic weapon traits**; not origin traits, armor mods, or artifact perks. |
| DO-WPK-002 | **Origin traits** are [Destiny Origin Trait](/prd/destiny-origin-trait/) (`origin_trait`), not `weapon_perk`. |
| DO-WPK-003 | Weapon **combat mod** socket is a [Destiny Weapon](/prd/destiny-weapon/) extra — not this object’s primary Synergy kind. |
| DO-WPK-004 | Detail shows **selected + can-roll + craft options** when data exists. |
| DO-WPK-005 | Set slot rows and dense Catalog lists do **not** show full perk grids (icon-only / glyphs). |
| DO-WPK-006 | Barrel, mag, and other non-trait columns follow the same density rules as traits (detail yes; set row no). |
| DO-WPK-007 | Invalid plugs cannot save; UI disables illegal options when known. |
| DO-WPK-008 | Exotic intrinsic/trait plugs are valid `weapon_perk` Synergy evidence (DBR-SYN-014). |
| DO-WPK-009 | Search/link UI labels exotic trait vs legendary when known (BR-SYN-012). |
| DO-WPK-010 | Hashes never primary UI (footer addendum only). |
| DO-WPK-011 | Enhanced/crafted badges shown when relevant. |
| DO-WPK-012 | Catalog/search may match hash; result row shows **name + icon**. |
| DO-WPK-013 | **Synergy coverage groups by perk family:** base and enhanced (or other family variants) of the same trait **match each other** for evidence/required-link satisfaction when family is known. |
| DO-WPK-014 | Roll storage and Set validity still use the **specific plug hash** (enhanced vs base remains distinct on the saved roll). |
| DO-WPK-015 | Weapon detail shows **all roll-relevant columns** by default (barrel, mag, traits, origin, …). Cosmetics (shader, tracker, etc.) collapsed or omitted. |
