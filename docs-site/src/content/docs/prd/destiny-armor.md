## 1. Definition (Destiny / DIM)

An **armor** piece is a Destiny inventory item for:

- Helmet, gauntlets/arms, chest, legs, or **class item**
- Bound to a **class** (Titan / Hunter / Warlock), except where game rules allow otherwise

DIM shows **EoF six stats**, **energy**, **tier**, **plugged mods**, and **armor set bonus** membership when applicable.

### Three product layers

| Layer | Meaning | Example |
| --- | --- | --- |
| **Identity** | Manifest item (hash) | “Lustrous Chromite Helm” |
| **Instance** | Owned copy with stats, energy, mods, power | High-stat vault copy |
| **Desired / unpinned** | Identity without instance pin | Wishlist piece; stats unknown |

### Two stat views (important)

| View | Meaning | Where |
| --- | --- | --- |
| **Base roll** | White/base armor stats (armor_stats plugs); excludes equipped armor mods, masterwork, tuning | Armor **Set board** / set totals (DBR-STAT-008, BR-SET-011) |
| **Live stats** | Instance stats as equipped/modded when product shows live ItemStats | Catalog instance cards, inventory-style detail when appropriate |

Do not mix the two without labeling.

| Surface | Show on row | Detail only |
| --- | --- | --- |

### Density by surface

| Surface | Armor detail depth |
| --- | --- |
| Catalog list | Icon + glyphs; exotic badge; **no stats** (v1) |
| Catalog / Set **detail** | Stats (labeled base vs live), energy, mods, set bonus, acquire/farm, exotic callout |
| Set **slot row** | Icon (+ exotic badge) + **tiny six-stat strip** (base when known) |
| Armor Set **board** | Base-roll per-piece + totals (not live modded) |
| Loadout readout | Icon strip; expand for detail |

### Catalog armor browse — default sort (identity list)

1. **Slot** (helmet → arms → chest → legs → class item)  
2. **Exotic** (exotics grouped/first)  
3. **Class** (when mixed)  
4. **Tier** (when known)  

### Owned instances of one identity — default sort

1. **Slot** (usually same)  
2. **Class** (usually same)  
3. **Base stat total** (highest first)  

Power is fallback when base total unknown.

## 5. Hard vs soft

### Hard

| Rule | Where |
| --- | --- |
| Legal armor slot for fill | Set / constrained Catalog |
| Class match for Armor Set | [Domain Set](/prd/domain-set/) |
| ≤1 exotic armor per Armor Set / loadout | Set / Variant |
| Energy capacity for mods | Mod Set / DBR-MOD-* |
| Slot-scoped mods must match piece | Mod Set |
| Set-bonus constraint membership + tier when set | Armor Set |

### Soft / display

| Topic | Rule |
| --- | --- |
| Soft stat targets | Warning only |
| Set bonus coverage (no constraint) | Soft on variant |
| Exotic blocking set bonus | Soft warn |
| Acquire/farm | Show when data exists; never invent |

### Parallel to weapon “can roll” / craft (armor)

| ID | Rule |
| --- | --- |
| DO-ARM-001 | Armor **detail** shows set bonus 2pc/4pc (or explicit no set bonus). |
| DO-ARM-002 | When Destiny data includes **possible class-item perk options** (or other armor plug pools), detail shows them with selected distinct (same spirit as can-roll). |
| DO-ARM-003 | Legendary armor random **stat** distribution: show **this instance’s** base stats; do not invent a full “possible stat ranges” UI unless data already supports it honestly. |
| DO-ARM-004 | Acquire/farm on detail when data exists (same as DO-WPN-030–036 pattern). |
| DO-ARM-005 | Set **slot rows**: icon (+ exotic badge) + **tiny six-stat strip** (base when known). Full mods/set-bonus/acquire on detail only. |
| DO-ARM-006 | Hashes never primary UI (footer addendum only). |
| DO-ARM-007 | Armor Set **board** uses **base roll** only (DBR-STAT-008). |
| DO-ARM-008 | Catalog instance / live detail may show live stats; must not be unlabeled as base roll. |
| DO-ARM-009 | Catalog **list** rows: no stat numbers in v1 (icon + glyphs only). |
| DO-ARM-010 | Selected armor mods: **detail only** on Catalog list (not mod icons on list rows). |
| DO-ARM-011 | Owned-instance default sort: slot → class → **base stat total** (highest first). |
