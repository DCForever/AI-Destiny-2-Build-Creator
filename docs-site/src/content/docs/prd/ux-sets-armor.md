## Job

Create and maintain **Armor Sets** as composition packages: class-bound board of owned instance pins, base-roll stats only, optional set-bonus goals, fill primarily via **Optimizer** (confirm-only) and secondarily via **owned compare pick**.

## Journeys (MVP)

1. Library → New Armor → Type → Class → optional bonus goals → empty board  
2. Optimize → constrain exotic + min/max stats → pick one kit row → confirm apply  
3. Per-slot Pick → owned compare → pin/replace with confirm  
4. Edit tags on detail or board  
5. Save (≥2 pieces + goals complete) · Delete (confirm / SET_IN_USE)

## IA

- **Route:** `/sets` dual-pane library  
- **Lifecycle:** large modal (create / board / compare / optimize)  
- **Not:** Catalog embed as Set editor; Synergy Type chrome in this slice
