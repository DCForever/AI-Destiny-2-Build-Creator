# Origin Trait — Destiny object

> [!abstract] One-liner
> Foundry/source-column trait on many weapons; fixed or craft-selectable; separate from legendary column perks.

Hub: [Destiny Objects](/prd/destiny-objects/) · Host: [Destiny Weapon](/prd/destiny-weapon/) · Sibling: [Destiny Weapon Perk](/prd/destiny-weapon-perk/)

> [!note] DIM reuse
> Presentation follows DIM origin position in the weapon perk layout (DBR-UI-001–005).  
> Visual refs: repo `docs/dim-reference-screenshots/Weapon Overview.png`, `Weapon Perk Info Popup.png`.  
> **Product diverge:** Set slot rows icon-only; origin detail with full weapon roll on detail surfaces.

## 1. Definition (Destiny / DIM)

An **origin trait** is a weapon trait tied to a **foundry, activity family, or source column** — not a free legendary third/fourth column perk.

| Role | Meaning |
| --- | --- |
| **Source identity** | Often shared across a foundry/activity weapon family |
| **Roll plug** | Stored on the weapon roll when the item has an origin socket |
| **Fixed vs selectable** | Many drops fix the origin; craft/reshape may offer choices when game allows |

DIM shows it in the perk layout (origin column / position) with other plugs.

### Not this object

| Object | Difference |
| --- | --- |
| [Destiny Weapon Perk](/prd/destiny-weapon-perk/) | Legendary columns + exotic traits; Synergy `weapon_perk` |
| Weapon combat mod | Adept/major/minor mod socket on weapon |
| Frame / archetype | Item archetype field on [Destiny Weapon](/prd/destiny-weapon/), not a plug object |

**Synergy:** use link kind `origin_trait` — **do not** store origin plugs as `weapon_perk`.

| [Area Catalog](/prd/area-catalog/) | Weapon detail; Universal; reverse lookup hosts |
| Soft guidance | Coverage / evidence only |

### Validity (hard)

When the weapon has an origin socket and a selection is stored, it must be a **valid origin for that item**.  
Invalid origin on save → reject (same family as perk validity — BR-ROLL-004 spirit).

Weapons with **no** origin socket: no origin required.

## 5. Hard vs soft

### Hard

| Rule | Where |
| --- | --- |
| Invalid origin plug for weapon when selected → cannot save | Weapon Set / roll |
| Do not treat origin as `weapon_perk` in Synergy | Synergy validation |

### Soft

| Topic | Rule |
| --- | --- |
| Synergy origin coverage | Soft except required-link pins on default |
| Foundry flavor text | Display only |

### Object rules

| ID | Rule |
| --- | --- |
| DO-ORG-001 | Origin trait is a **distinct plug kind** from legendary/exotic [Destiny Weapon Perk](/prd/destiny-weapon-perk/). |
| DO-ORG-002 | Synergy link kind is `origin_trait`, not `weapon_perk`. |
| DO-ORG-003 | Stored on weapon roll when the item has an origin socket. |
| DO-ORG-004 | Detail shows selected origin; show can-roll/craft alternates when data exists. |
| DO-ORG-005 | Set slot rows and dense Catalog lists do not show origin icons. |
| DO-ORG-006 | Invalid origin for host weapon cannot save when a selection is present. |
| DO-ORG-007 | Hashes never primary UI (footer addendum only). |
| DO-ORG-008 | Reverse lookup of host weapons is a Catalog/Synergy product use. |
| DO-ORG-009 | Catalog/search may match hash; result row shows **name + icon**. |
| DO-ORG-010 | Fixed origins still display clearly; selectable origins follow craft/pool data — never invent options. |
