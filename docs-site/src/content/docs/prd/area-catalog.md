## Glossary (fixed terms)

| Term | Meaning |
| --- | --- |
| **Catalog** | App surface to browse manifest items and owned instances |
| **Identity row** | One manifest item (e.g. one weapon definition) |
| **Owned instance** | One inventory copy of an identity (pins, rolls) |
| **Facet** | One filter dimension (element, ammo, slot, …) |
| **Include** | Match any selected value in that facet (OR within facet) |
| **Exclude** | Drop any item that matches the value |
| **Constrained pick** | Catalog opened from Set fill / Build with locked domain rules |
| **Universal mode** | Mixed-kind search across weapons, armor, mods, perks, kit pieces, etc. |

## 1. Role

| Field | Content |
| --- | --- |
| **Product role** | Supporting composition aid |
| **One-liner** | Browse and filter Destiny data to pick gear and inspect rolls |
| **Primary journey** | Shorten fill-slot and set curation; never replace intent-first Build compose |

## 2. Users and jobs

- **Primary job:** Find an identity or owned copy that matches facets and text.
- **Secondary jobs:** Inspect weapon/armor detail; pick into Set or Build fill; see linked library Synergies on targets.
- **Not for:** Primary inventory product; vault transfer; build identity editing; DIM notes/tags product.

## 3. Shape

| Aspect | Rule summary |
| --- | --- |
| Modes | **Weapons** tab, **Armor** tab, and **Universal** (mods/perks/kit pieces and mixed kinds) |
| Landing | Restore **last used** mode/tab |
| Auth | Signed-in: manifest + owned. Signed-out: manifest browse with not-owned indication |
| Filter model | Facets include/exclude + free-text + optional synergy membership + exotic tri-state |
| Semantics | OR within include facet; AND across facets; any exclude drops; free-text ANDs |
| Group-by | Optional partition of results; does not change filter semantics |
| Detail | DIM North Star; icon-first; perks/stats/set bonus fidelity |
| Embed | Constrained pick from Sets/Build locks domain (slot, class, set type, …) |
| Outbound | From hit: create/add **Set** or **Synergy** via shared lifecycles — not Build kit attach |

## 3a. Constraints (hard vs soft)

### Hard

| Constraint | Rule |
| --- | --- |
| **Not primary job** | Catalog must not become the home of the product (DBR-PUR-002) |
| **Filter semantics** | Include OR / across AND / exclude drop must hold (BR-CAT-006) |
| **Constrained pick** | Embedded fill must enforce the caller’s hard domain rules (slot, class, exotic exclusivity, set type) |
| **Shared lifecycles** | Create/Edit Set or Synergy from Catalog opens [Area Sets](/prd/area-sets/) / [Area Synergy](/prd/area-synergy/) lifecycle — no lite forks |
| **Pick ≠ attach** | Catalog pick selects identity/instance for a slot or wizard; it does not replace variant Attach panel rules |

### Soft

| Topic | Rule |
| --- | --- |
| Performance | Aim &lt;5s filter/search (BR-CAT-005); soft product bar |
| Synergy facet | Optional include/exclude membership |
| Advanced query (Peggy) | Later phase; not v1 hard requirement |
| Group-by | Optional convenience |

## 4. In scope / out of scope

**In**

- `/catalog` and embedded pick surfaces
- Weapons and armor (and Universal mixed kinds per BR-CAT-009)
- Facet chips: include / exclude / off cycle
- Free-text search
- Owned instance list and pick for pins
- Item detail (stats, perks, origin, set bonus, reverse synergies)
- Signed-out manifest browse
- Entry to Set/Synergy create-add wizards from hits

**Out**

- Catalog as primary product job
- Full boolean query language as v1 requirement
- Vault transfer / DIM notes-tags product
- Build identity editing
- Build kit attach from Catalog (use variant Attach)

## 5. Success

| Signal | Pass when |
| --- | --- |
| Facet browse | Multi-dimension include/exclude + text works |
| Detail | Weapon/armor detail usable for set fill |
| Owned copies | User can distinguish and choose instances |
| Embed | Constrained pick respects domain locks |
| Not primary | User still composes on Build, not only in Catalog |

## 6. Canonical rules (Catalog rule pack)

### 6.1 Purpose

| ID | Rule |
| --- | --- |
| DBR-PUR-002 | Inventory organization is supporting, not the primary job. Catalog is a composition aid. |
| DBR-ROLL-010 | Catalog browse supports multi-dimension filtering and optional group-by. Catalog is not a separate product job. |
| BR-CAT-009a | Catalog must not replace intent-first Build compose. |

### 6.2 Browse modes and auth

| ID | Rule |
| --- | --- |
| BR-CAT-001 | User can filter/search the full weapon catalog (manifest). |
| BR-CAT-002 | Signed-in user can filter/search owned weapons (inventory sync). |
| BR-CAT-003 | Equivalent filtering for armor and owned armor. |
| BR-CAT-004 | Unsigned users browse manifest with clear not-owned indication. |
| BR-CAT-009 | **Universal** mode searches mixed kinds: weapons, armor, mods, perks, traits, set bonuses, artifact perks, subclass pieces. |
| BR-CAT-009b | From Universal (or hit detail), user may create/add **Sets** or **Synergies** only — not Build kit attach. |
| BR-CAT-010 | Primary chrome: **Weapons** tab, **Armor** tab, and **Universal**. No separate required Mods tab in v1 (mods live in Universal). |
| BR-CAT-010a | Opening `/catalog` restores the user’s **last used** mode/tab. First visit defaults to Weapons (or product default Weapons). |
| BR-CAT-010b | Advanced boolean query (Peggy / JQL-style) is **out of v1**. Simple facets + free-text only for v1. |

### 6.3 Filter model

| ID | Rule |
| --- | --- |
| BR-CAT-006 | Across facets: **AND**. Within a facet’s includes: **OR**. Any **exclude** match drops the item. Free-text further **AND**s. |
| BR-CAT-006a | Facet chip cycle: **off → include → exclude → off** (or equivalent clear UX). |
| BR-CAT-006b | Core dimensions include: element, ammo, archetype/frame, slot, class, exotic constraint, free-text. |
| BR-CAT-007 | Results may **group by** one or more dimensions. Group-by does not replace filter semantics. |
| BR-CAT-008 | Catalog may filter by library **synergy membership** (include/exclude). |
| BR-CAT-005 | Filter/search should complete in under 5 seconds under normal data (product performance bar). |
| DAC-NME-003 | Multi-facet browse is testable. |

### 6.4 Owned instances and pick

| ID | Rule |
| --- | --- |
| BR-CAT-010c | Weapons browse default sort: **slot → exotic → ammo → archetype** ([Destiny Weapon](/prd/destiny-weapon/)). |
| BR-CAT-010d | Armor browse default sort: **slot → exotic → class → tier** ([Destiny Armor](/prd/destiny-armor/)). |
| BR-CAT-011 | For an identity, user can list owned instances when signed in and synced. |
| BR-CAT-011a | Weapon instances of one identity: prefer **higher power** first. |
| BR-CAT-011b | Armor instances of one identity: **slot → class → base stat total** (highest first) ([Destiny Armor](/prd/destiny-armor/) DO-ARM-011). |
| BR-CAT-011c | Armor Catalog **list** rows: no stat numbers in v1; mods detail-only. |
| BR-CAT-012 | Instance cards show kind-appropriate detail (weapon perks; armor tier/stats/set bonus). |
| BR-CAT-013 | User may select one instance for pin/wishlist flows when in pick mode. |
| BR-CAT-014 | Constrained pick locks domain (e.g. armor slot, class, weapon bucket, set type exotic rules). |
| BR-CAT-015 | Illegal options under hard domain rules are not selectable in constrained pick. |
| DBR-ROLL-001 | Catalog identities may be used as wishlist desired rolls on variants/sets. |

### 6.5 Detail and presentation

| ID | Rule |
| --- | --- |
| DBR-UI-001 | DIM is North Star for item/perk/stat presentation. |
| DBR-UI-005 | Icon-first for Destiny entities. |
| BR-CAT-016 | Weapon detail shows roll-relevant perks and plugs with readable names when resolved. |
| BR-CAT-016a | Weapon detail shows **what can roll** per column (manifest pool), with selected plug distinct ([Destiny Weapon](/prd/destiny-weapon/) DO-WPN-001–007). |
| BR-CAT-016b | Never show plug hashes as primary labels; names/icons only. Hashes only as footer addendum on description ([Destiny Weapon](/prd/destiny-weapon/) DO-WPN-010–013). |
| BR-CAT-016c | When craftable (including **craftable exotics**), weapon detail shows **possible crafted options** (levels, enhanced choices, shaped selections). Current craft is the selected plugs — do not duplicate a separate current-craft list. | BR-CAT-016d | When Destiny data includes acquire/farm sources, weapon detail shows them; never invent sources ([Destiny Weapon](/prd/destiny-weapon/) DO-WPN-030–036). |
| BR-CAT-017 | Armor detail shows EoF stats and set bonus 2pc/4pc when known; explicit empty when none. |
| BR-SYN-004 | Linked library Synergies surface on matching targets (reverse lookup; production surfaces). |
| DBR-ROLL-007 | Catalyst status display-only. |
| DBR-ROLL-008 | Deepsight/pattern display-only. |
