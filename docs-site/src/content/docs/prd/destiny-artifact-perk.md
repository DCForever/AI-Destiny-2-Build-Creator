# Artifact Perk — Destiny object

> [!abstract] One-liner
> Unlock on one of the six fixed seasonal artifacts; variants store full artifact config and equip applies it.

Hub: [Destiny Objects](/prd/destiny-objects/) · Edited in: [Domain Variant](/prd/domain-variant/) General · Related: [Domain Synergy](/prd/domain-synergy/) (`artifact_perk`)

> [!note] DIM reuse
> Presentation follows DIM-style artifact / seasonal unlock density where practical (DBR-UI-001–005).  
> **Product diverge:** exactly **six fixed artifacts** (DBR-ART-001); not a growing catalog of custom artifacts. Workflows are Variant General + equip — not DIM vault product.

---

## 1. Definition (Destiny / DIM)

| Term | Meaning |
| --- | --- |
| **Artifact** | One of **six fixed** seasonal artifacts the Guardian can switch (API-backed). Not expected to grow (DBR-ART-001). |
| **Artifact perk / unlock** | A selectable node/mod on that artifact’s tree or grid |
| **Artifact config** | Full set of selected unlocks for the chosen artifact on a variant |

An **artifact perk** is one unlock definition. A **variant’s artifact config** is the full selection applied on equip.

DIM loadouts can store artifact configuration; we treat config as **per-variant** under **General**.

### Product placement

| Concern | Owner |
| --- | --- |
| Which artifact (1 of 6) | [Domain Variant](/prd/domain-variant/) — **General**; exactly one (DBR-ART-002) |
| Full unlock config | Variant General; equip applies (DBR-ART-003) |
| Default complete | Artifact **selected** + config **filled** (DBR-ART-003a / §3.2) |
| Build identity | **Not** identity (DBR-ID-010) |
| Synergy evidence | Link kind `artifact_perk` → individual unlocks |

### Default complete (“filled” bar)

| Requirement | Rule |
| --- | --- |
| Artifact | Exactly one of six selected |
| Config | **Non-empty** and **valid** for that artifact |
| Filled (product) | Every unlock the artifact model treats as **part of the active equip config** is set according to game/API structure when known (columns/tiers/points the product models as required for apply) |
| Empty config | **Fails** default compose complete (DAC-VAR-008) |
| Non-default variants | May save with incomplete config under compose rules for non-default; equip/export still needs a valid applyable config when applying artifact |

When exact tree capacity is unknown, do not invent unlocks: require a config the API can apply, and show honest incomplete state rather than fake fills.

### Switch artifact

| Event | Behavior |
| --- | --- |
| Change which of six | Variant-local (not Build confirm/fork) |
| Prior config | Cleared or invalidated; user rebuilds for new artifact |
| Default | Becomes incomplete until new config is filled |

## 5. Hard vs soft

### Hard

| Rule | Where |
| --- | --- |
| Exactly one of six artifacts per variant | Variant General |
| Default: artifact + filled config | Default compose complete |
| Invalid config for artifact cannot save when known | Validation |
| Do not invent a 7th artifact | Product (DBR-ART-001) |

### Soft

| Topic | Rule |
| --- | --- |
| Synergy artifact_perk coverage | Soft except required-link pins on default |
| Retired / seasonal-ended unlocks | Soft warn when data marks them |
| Non-default incomplete config | Allowed to save under non-default gap rules |

### Object rules

| ID | Rule |
| --- | --- |
| DO-ART-001 | Artifact perks are unlocks on one of **six fixed** artifacts — not a free-growing item type. |
| DO-ART-002 | Each variant selects **exactly one** artifact (General). |
| DO-ART-003 | Each variant stores a **full artifact config**; equip **applies** it. |
| DO-ART-004 | **Default** requires artifact selected **and** config **filled** (not empty). |
| DO-ART-005 | Artifact config is **variant-local**, not Build identity. |
| DO-ART-006 | Presentation is icon-first tree/grid; selected state clear. |
| DO-ART-007 | Hashes never primary UI (footer addendum only). |
| DO-ART-008 | Synergy link kind `artifact_perk` targets individual unlocks. |
| DO-ART-009 | Switching artifact invalidates prior config; user rebuilds. |
| DO-ART-010 | Do not invent artifacts, unlocks, or seasons not in loaded data. |
| DO-ART-011 | Catalog/search may match hash; result row shows **name + icon**. |
| DO-ART-012 | “Filled” follows the artifact’s equip-config model when known; never fake a complete grid without data. |
