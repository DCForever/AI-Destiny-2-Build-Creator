# Synergy — area product description

> [!abstract] One-liner
> The workspace that owns the library Synergy lifecycle: create, edit, link evidence, delete.

Catalog: [Products](/prd/products/) · Domain: [Domain Synergy](/prd/domain-synergy/)

> [!note] Rule pack
> Domain rules: **[Domain Synergy](/prd/domain-synergy/) §6**.
> This note owns area and UI rules only.
> Wording follows **ASD-STE100** spirit.

## 1. Role

| Field | Content |
| --- | --- |
| **Product role** | P2 library. Owns library Synergy lifecycle UI. |
| **One-liner** | Curate Type + Object synergies for bridge, coverage, and suggestions. |
| **Primary journey** | User builds a library. Build and Set designations bridge to it. |

## 2. Users and jobs

- **Primary job:** Create library Synergies with clear designation and solid evidence links.
- **Secondary jobs:** Mark required links; personal types; reverse lookup; LLM propose-for-confirm.
- **Not for:** Build identity editor; auto LLM; free-text instead of designation.

## 3. In scope

- Library list, filter, search
- Shared lifecycle: create, edit, detail, delete
- Designation on create only (locked on edit)
- Description + link list (add/remove; evidence vs required)
- Link pickers by kind with manifest validation
- Type picker from product enum; subType when required
- Optional description
- Reverse “used by” / links-from-target where product exposes it
- Manual LLM propose → confirm into lifecycle (enum types only)
- Prefill from in-flow Build entry

## 4. Out of scope

- Forcing a full library before compose
- Editing type/subtype after create
- Auto LLM without confirm
- Concept tags as synergy identity
- A second in-flow-only Synergy editor
- Personal invent-a-type UI in v1

## 5. Success

| Signal | Pass when |
| --- | --- |
| CRUD | User can create and edit library Synergies |
| Same lifecycle | Library and in-flow match (DAC-SYN-001) |
| Immutable designation | Edit UI locks type/subtype |
| Unique designation | Duplicate type+subType blocked |
| Links | Valid kinds only; no duplicate target on one row |
| LLM | Confirm step required; no free type keys |
| In-flow | Build can open lifecycle without deep library |
