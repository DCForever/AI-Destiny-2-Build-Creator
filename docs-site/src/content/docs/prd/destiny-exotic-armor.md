# Exotic Armor — Destiny object

> [!abstract] One-liner
> Exotic-tier armor with a unique perk; classic pieces may pin Build identity by item; exotic class items are intent-locked with per-variant config.

Hub: [Destiny Objects](/prd/destiny-objects/) · Base item: [Destiny Armor](/prd/destiny-armor/) · Related: [Destiny Ability](/prd/destiny-ability/) (exotic ability pins) · [Destiny Armor Set Bonus](/prd/destiny-armor-set-bonus/)

> [!note] DIM reuse
> Presentation follows DIM exotic armor overview (DBR-UI-001–005).  
> Visual refs: repo `docs/dim-reference-screenshots/Exotic Armor Overview.png`.  
> **Product diverge:** classic exotic **item** can be Build identity; exotic **class items** are not item-hash identity — not DIM’s vault product.

## 1. Definition (Destiny / DIM)

**Exotic armor** is armor with **exotic tier** and a unique exotic perk (or class-item perk configuration).

It is still [Destiny Armor](/prd/destiny-armor/) for slot, class, stats, energy, and mods. This note owns **exotic-specific** product rules.

### Two product families (critical)

| Family | Slots | Identity behavior |
| --- | --- | --- |
| **Classic exotic** | Helmet, arms, chest, legs (non–class-item) | When set on Build: identity by **item hash** (DBR-ID-003). Variants may use different **instances** of that same item. |
| **Exotic class item** | Class item only | Fills the exotic-armor slot. **Not** item-hash identity. **Intent/synergy-locked** (DBR-ID-005). Variants may use different class items / perk configs that still fit designated synergies (**soft** check). |

DIM shows exotic perk(s) prominently on detail.

### Counts as exotic armor for exclusivity

| Context | Rule |
| --- | --- |
| Armor Set | ≤1 exotic armor across slots; **exotic class item counts** (BR-SLOT-009) |
| Resolved loadout | ≤1 exotic weapon **and** ≤1 exotic armor (incl. class item) — hard (DBR-CMP-007) |
| Pair Set | Exotic armor half; must match build exotic armor when build has one set (BR-PAIR-001) |

## 4. Product use

| Product | How exotic armor appears |
| --- | --- |
| [Domain Build](/prd/domain-build/) | Optional classic exotic **item** identity (set/clear = confirm/fork). Class items **not** item-hash identity — intent soft. |
| [Domain Set](/prd/domain-set/) | Armor Set exotic ≤1; Pair exotic armor slot; optional set-bonus: non-exotic pieces must match family; exotic may soft-warn if it blocks bonus |
| [Domain Variant](/prd/domain-variant/) | Armor + Mods area; dual exotic hard; Pair armor match; class-item full config; exotic ability pins |
| [Domain Synergy](/prd/domain-synergy/) | Link kind `exotic_armor`: classic → item; class item → **perk config only** |
| [Area Catalog](/prd/area-catalog/) | Armor browse; exotic filter/sort; constrained pick |
| Soft guidance | Class-item “fits synergies” soft; exotic vs set bonus soft warn |

### Classic exotic on Build identity

| Event | Behavior |
| --- | --- |
| Set classic exotic item | Identity change → confirm or fork |
| Clear classic exotic item | Identity change → confirm or fork |
| Change to different classic item | Identity change → confirm or fork |
| Different **instance** of same item on variants | Allowed (not identity change) |
| Unset (no exotic identity) | Allowed — exotic armor optional (DBR-ID-004) |

### Exotic class item

| Event | Behavior |
| --- | --- |
| Pick class item / change perk config | **Variant-level** (or wishlist config) — not Build item-hash identity |
| Soft intent | Prefer configs that fit designated Synergies; soft-check only (DAC-VAR-005) |
| Store | Full selected perk config on instance or wishlist (DBR-ROLL-009) |
| Still exotic | Counts toward ≤1 exotic armor on set/loadout |

### Ability requirements

When game data says an exotic requires a specific Super / melee / grenade / class ability:

1. System **auto-proposes** ability pins  
2. User **confirms**  
3. **Mismatch blocks save** (DBR-SUB-005; [Destiny Ability](/prd/destiny-ability/) DO-ABL-009)

Do **not** invent requirements.

### Pair Sets

| Rule | Meaning |
| --- | --- |
| Both slots | Exotic weapon + exotic armor required to save/attach |
| Match build | Pair exotic armor must match build classic exotic when build has one set |
| Optional path | Exotics may also come from Armor/Weapon Sets or pins (DBR-CMP-004) |

## 5. Hard vs soft

### Hard

| Rule | Where |
| --- | --- |
| ≤1 exotic armor on Armor Set (class item counts) | Set (BR-SLOT-009) |
| ≤1 exotic armor + ≤1 exotic weapon on loadout | Variant (DBR-CMP-007) |
| Pair incomplete without both exotics | Pair Set |
| Pair armor ≠ build exotic armor when build has one | Pair / attach (BR-PAIR-001) |
| Classic exotic identity set/clear/change | Build confirm/fork |
| Exotic ability requirement mismatch | Save blocked after pin path |
| Class match for armor | Armor Set |

### Soft

| Topic | Rule |
| --- | --- |
| Class-item fits synergies | Soft check; variants may differ within intent |
| Exotic blocks armor set bonus target | Soft warn (BR-SET-056a) |
| Soft stat / coverage | Soft |
| Acquire missing | Omit or “source unknown” — never invent |

### Object rules

| ID | Rule |
| --- | --- |
| DO-EXO-001 | Exotic armor is exotic-tier [Destiny Armor](/prd/destiny-armor/) with exotic-specific product rules in this note. |
| DO-EXO-002 | **Classic** (non–class-item) exotic may be Build identity by **item hash** when set (DBR-ID-003). |
| DO-EXO-003 | Classic exotic identity is **optional**; unset is valid (DBR-ID-004). |
| DO-EXO-004 | **Exotic class items** are **not** item-hash identity; they are intent/synergy-locked with soft checks (DBR-ID-005). |
| DO-EXO-005 | Variants may use different **instances** of the same classic exotic item. |
| DO-EXO-006 | Exotic class items store **full perk config** (instance or wishlist) — DBR-ROLL-009. |
| DO-EXO-007 | Exotic class item **counts as exotic armor** for ≤1 exotic armor rules. |
| DO-EXO-008 | Dual exotic (weapon + armor) on loadout is hard-blocked beyond one of each. |
| DO-EXO-009 | Exotic ability requirements: auto-propose pins; confirm; mismatch hard — never invent requirements. |
| DO-EXO-010 | Presentation: exotic badge on rows; **exotic perk callout on detail**; class-item config on detail. |
| DO-EXO-011 | Hashes never primary UI (footer addendum only). |
| DO-EXO-012 | Synergy `exotic_armor` for **classic** exotics targets the **item hash**. |
| DO-EXO-012a | Synergy `exotic_armor` for **exotic class items** targets the **perk configuration** only (not the item shell). Coverage matches configs, not which class-item shell is equipped. |
| DO-EXO-013 | Pair exotic armor must match build classic exotic when build has one set. |
| DO-EXO-014 | Acquire/farm on detail when data exists; never invent. |
| DO-EXO-015 | Set-bonus constraint: non-exotic pieces must be family members; exotic may soft-warn if it blocks the target tier. |

## 6. Out of scope

- Multiple exotic armor pieces on one loadout  
- Treating exotic class item as classic item-hash identity  
- Full ornament/fashion suite as exotic product (see [Destiny Fashion Item](/prd/destiny-fashion-item/))  
- Inventing exotic perk text or ability requirements
