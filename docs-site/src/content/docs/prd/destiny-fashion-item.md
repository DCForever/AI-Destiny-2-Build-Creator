# Fashion Item — Destiny object

> [!abstract] One-liner
> Cosmetic or non-combat equippable: shaders, ornaments, ghost, sparrow, ship, emblem, finisher.

Hub: [Destiny Objects](/prd/destiny-objects/) · Sets: Fashion Sets ([Domain Set](/prd/domain-set/)) · Variant: [Domain Variant](/prd/domain-variant/) General

> [!note] DIM reuse
> Presentation is icon-first cosmetic density (DBR-UI-001–005).  
> **Product diverge:** fashion is a **non-combat layer** — not identity, not synergies/stats (DBR-FASH-005). Full DIM transmog/vault fashion tools are out of scope.

---

## 1. Definition (Destiny / DIM)

A **fashion item** is a cosmetic or non-combat equippable used for look and flair.

### Kinds in product scope (DBR-FASH-003)

| Kind | Notes |
| --- | --- |
| **Shader** | Colorway on gear |
| **Ornament** | Visual override on weapon/armor when applicable |
| **Ghost** | Ghost shell |
| **Sparrow** | Vehicle |
| **Ship** | Jumpship |
| **Emblem** | Emblem |
| **Finisher** | Finisher |

### Out of fashion object (domain)

| Exclude | Why |
| --- | --- |
| Emotes | Domain out of scope for fashion layer |
| Consumables | Not fashion |
| Combat gear | [Destiny Weapon](/prd/destiny-weapon/), [Destiny Armor](/prd/destiny-armor/), etc. |

DIM can include many cosmetics on loadouts; we apply fashion **when specified** on equip/export.

### Product placement

| Concern | Owner |
| --- | --- |
| Fashion package | [Domain Set](/prd/domain-set/) — **Fashion Set** type |
| Attach / apply on variant | [Domain Variant](/prd/domain-variant/) — **General** (BR-VAR-037) |
| Compose complete | **Optional** — not required for default (DBR-CMPL-001b) |
| Identity / Synergy / soft stats | **Never** (DBR-FASH-005) |

## 4. Product use

| Product | How fashion appears |
| --- | --- |
| [Domain Set](/prd/domain-set/) | **Fashion Sets**; no Synergy Type designations (BR-SET-033); own occupancy rules (not Weapon/Armor min-slot rules) |
| [Domain Variant](/prd/domain-variant/) | Attach Fashion Set under **General**; optional for compose complete |
| [Domain Build](/prd/domain-build/) | Not identity |
| [Domain Synergy](/prd/domain-synergy/) | **No** fashion link kinds in v1 |
| Equip / DIM export | Apply specified fashion slots; omit leaves cosmetics as-is |
| Soft stats / suggestions | Fashion does **not** drive them |

### Omit semantics

| State | Equip behavior |
| --- | --- |
| Slot filled | Apply that cosmetic |
| Slot **omitted** / empty in product | **Leave character cosmetics as-is** (DBR-FASH-004) |
| Explicit “clear” if API supports | Only when product exposes clear and API allows — do not invent |

### Fashion Set lifecycle

Same shared Set lifecycle (create/edit/delete) as other Sets, with Fashion-specific slots and **no** Synergy Types.  
Attach is a separate operation under Variant General (same Create/Edit/Attach split spirit as other Sets).

## 5. Hard vs soft

### Hard

| Rule | Where |
| --- | --- |
| Fashion is not Build identity | Build / validation |
| Fashion Sets must not designate Synergy Types | Set |
| Illegal fashion item for slot/kind when known | Fashion Set fill |

### Soft

| Topic | Rule |
| --- | --- |
| Default complete without fashion | Allowed |
| Preview / match warnings | Soft only |
| Ornament on combat gear rows | Polish; not required on combat set slot rows |

### Object rules

| ID | Rule |
| --- | --- |
| DO-FASH-001 | Fashion items are cosmetic/non-combat equippables in the kinds list above. |
| DO-FASH-002 | Fashion attaches **per variant** via Fashion Sets under **General**. |
| DO-FASH-003 | Fashion is **optional** for composition complete. |
| DO-FASH-004 | Omitted slots **leave cosmetics as-is** on equip. |
| DO-FASH-005 | Fashion is **not** identity and does **not** drive synergies, suggestions, or combat stats. |
| DO-FASH-006 | Fashion Sets do **not** designate Synergy Types. |
| DO-FASH-007 | Presentation is icon-first; no combat stat chrome. |
| DO-FASH-008 | Hashes never primary UI (footer addendum only). |
| DO-FASH-009 | No Synergy link kind for fashion items in v1. |
| DO-FASH-010 | Equip and DIM export include fashion **when specified**. |
| DO-FASH-011 | Emotes and consumables are out of this object. |
| DO-FASH-012 | Acquire/farm on detail when data exists; never invent. |
