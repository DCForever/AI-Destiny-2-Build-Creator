## Job & posture

- **For:** Find weapon identities / owned copies; inspect selected rolls, can-roll, possible crafted, exotic identity.  
- **Not:** Product home, vault manager, live Set/Synergy create (stubs only until those areas return).  
- Aligns DBR-PUR-002 / Area Catalog supporting role.

## Primary journeys

1. Open Catalog → Weapons (only mode this slice).  
2. Browse **All** (default) or **Owned**; free-text + facet chips.  
3. Select identity → **detail sidebar** (desktop) or push (mobile later).  
4. Optionally toggle **Can roll** / **Possible crafted**; inspect exotic intrinsic + catalyst.  
5. Stub outbound (disabled) for Set/Synergy until shared lifecycles return.

## Information architecture

| Aspect | Decision |
| --- | --- |
| Modes this slice | Weapons only |
| Default scope | All / manifest |
| Results | Flat **icon grid** |
| Desktop | Grid + **full-height detail sidebar** (~400px) |
| Filters | Icon/color chips, one primary line when space allows + More |

## Interaction principles

- Facet cycle: off → include → exclude → off  
- OR within facet, AND across, exclude drops, free-text AND  
- Can roll / Possible crafted **toggles off by default**  
- Possible crafted uses **same column UI as Perks**  
- No duplicate “current craft” list (selected plugs = current)  
- Exotic **intrinsic** separate, near **Catalyst**  
- Soft-only catalyst; never invent pools/sources
