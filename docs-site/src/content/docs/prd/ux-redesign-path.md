## Principles (short)

1. Finish the **active** mode/area to an **exit gate** before the next full redesign.
2. Weapons residuals ≠ permission to start Armor.
3. System APIs (DART-*) may interleave; chrome still follows Catalog phase order unless we re-point the path.
4. Catalog is a **composition aid**, not product home (DBR-PUR-002).
5. **Larger UX always uses workflows** — `area-ux-redesign` or `area-ux-component` → human mockup gate → `area-implement` → Capture. System-only packages may land without that loop; **paired visible chrome must not**.
