# Sets — area product description

> [!abstract] One-liner
> The workspace that owns the Set lifecycle: create, edit, fill, and delete.

Catalog: [Products](/prd/products/) · Domain: [Domain Set](/prd/domain-set/)

> [!note] Rule pack
> Domain rules live on [Domain Set](/prd/domain-set/) §6.
> This note owns area and UI rules only.
> Wording follows **ASD-STE100** spirit.

## 1. Role

| Field | Content |
| --- | --- |
| **Product role** | P2 library. Owns Set lifecycle UI. |
| **One-liner** | Create and maintain typed Sets for attach into Builds. |
| **Primary journey** | User opens the Set lifecycle. User saves a valid package. User may attach from Build. |

## 2. Users and jobs

- **Primary job:** Build reusable Weapon, Armor, Mod, Pair, and Fashion Sets that pass package rules.
- **Secondary jobs:** Fill slots, pin instances, designate Synergy Types, filter by Type, see used-by builds, read armor base-roll board.
- **Not for:** Build identity, vault management, a second Set editor inside Build.

## 3. In scope

- Sets library: list, filter, search
- Shared lifecycle: create, edit, detail, fill, delete
- Synergy Type designation on Weapon, Armor, Mod, Pair (same controls every entry)
- Optional **armor set bonus constraint** on Armor Sets (family + 2pc/4pc)
- Filter library and attach picker by Synergy Type
- Prefill from other entry points
- Save gates and clear errors
- Fill pickers by set type and slot (and bonus family when constrained)

## 4. Out of scope

- Build identity (Build keeps its own Synergy Types)
- Synergy Types on Fashion Sets
- Armor set bonus constraints on non-Armor Set types
- Fashion in combat stats or synergies
- Auto-apply optimizer without confirm
- A Build-only or finish-only Set editor

## 5. Success

| Signal | Pass when |
| --- | --- |
| CRUD | User can create and edit each set type |
| Same lifecycle | Library path and Build path match (DAC-SET-001) |
| Package min | Under-min save fails with a clear reason |
| Synergy Types | User can designate and filter by Type (DAC-SET-006–008) |
| Armor set bonus | User can set constraint; fill and save respect family and tier (DAC-SET-009–011) |
| Fill | Pickers block illegal exotic, slot, class, and constrained bonus choices |
| In-flow | Build can open this lifecycle without a deep library |
